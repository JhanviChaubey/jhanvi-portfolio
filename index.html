Environmental Intelligence React · Weather API 2026

GOROM

Environmental Intelligence Platform

Standard weather applications report temperature. GOROM interprets it.

The system represents how heat actually feels - not just what a thermometer reads by combining environmental variables into a custom discomfort index calibrated for Indian climate conditions. Built in React with live weather API integration, GOROM bridges the gap between raw meteorological data and human thermal perception.

Problem Raw temperature data fails to communicate real human thermal discomfort, especially in high-humidity environments.
Approach Custom discomfort index combining temperature, humidity, and heat index - localized for Indian climate zones.
Stack React, OpenWeather API, custom index algorithm

AI Systems Terrain Intelligence 2026

ITADMS

Intelligent Terrain-Aware Defensive Mobility System

A proposed AI-assisted terrain intelligence system designed to improve operational awareness in complex environments. ITADMS explores how machine learning can synthesize topographic data, real-time sensor input and route history to support decision-making in high-stakes mobility scenarios. The project examines human-AI collaboration in time-sensitive contexts.

Knowledge Systems Devopia 3.0 2026

Nexus

Knowledge Navigation Platform

Developed during Devopia 3.0, Nexus explored ways to organize fragmented information into navigable knowledge structures. The project addressed a core problem in modern information environments: data exists everywhere but remains difficult to traverse meaningfully. Nexus proposed a graph-based approach to connecting related concepts across sources.

03 — Research

Published & Under Review

Under Review · Elsevier

Advances in Neuroimaging Diagnostics for Cognitive Diseases Using AI

This paper surveys the application of deep learning and machine learning models to neuroimaging data — MRI, PET, and fMRI — for the early diagnosis of cognitive conditions including Alzheimer's disease and related dementias. The work synthesizes recent literature on convolutional architectures, attention mechanisms, and transfer learning applied to medical imaging pipelines, and identifies current limitations in interpretability and dataset diversity.

Keywords: Neuroimaging · Deep Learning · Cognitive Diagnostics · Medical AI
